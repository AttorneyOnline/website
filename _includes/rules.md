
# Server Listing Rules

#### Last updated: October 8, 2026

---

All servers on the Server Listing are run by the community. Any user can host any server on any server software. Please exercise caution and due diligence as with anything online.

Each server owner is responsible for their own server, their rules and moderation. Attorney Online is only responsible for allowing these servers to rent space on the Server Listing (commonly referred to as the Lobby or the Master Server). If any of the servers are in breach of these rules they will be removed from the listing.

A Server Owner is the person who is responsible for managing the server, its moderation team and rules, and also responsible for listing their server on the Server Listing and who has the ability to change the server name, description and configuration.

The rules are as follows:

1. For us to be able to contact you, your server must feature at least one of the following:  
   1. A discord handler of the server owner featured in the server listing's description  
   2. An X (formerly Twitter) handler of the server owner featured in the server listing's description  
   3. A bluesky handler of the server owner featured in the server listing's description  
   4. A working email address the server owner can access and use in the server listing's description  
2. If there are no language markers, the default assumed language used by the server is English. However, if the server allows languages other than English please mark it in your server listing's name with the language brackets (e.g.  \[EN\]\[DE\]\[RU\] Server Name for English/German/Russian)  
3. Your server must be joinable by the latest supported version of the Attorney Online client and it must be possible to chat and participate using that client. Participation includes having access to the In-Character Chat, Out-Of-Character Chat, seeing other people's Characters and seeing the Backgrounds.  
   1. In return, the Attorney Online Development Team will make sure that you are warned at least two months in advance via a news post of any upcoming breaking changes that would result in your server being incompatible and will be ready to assist you with remedying the issue if your server software is open source. If the update releases and your server still remains incompatible, you have an additional two week grace period until your server is removed from the listing.  
4. Breaking software licenses and failing to disclose source code for software that requires it will be grounds for your server being delisted. For example, modified code of AGPLv3-licensed software \- such as the [Tsuserver3](https://github.com/AttorneyOnline/tsuserver3) server or the [WebAO](https://github.com/AttorneyOnline/webAO) client \- requires you to link to the source code in your server listing's description.  
5. When you advertise on the Attorney Online Server Listing you agree to never disclose and publicize people's IP addresses or Hardware ID's. Only the server software and the server owner should have access to those IP addresses or Hardware ID's and they must be sufficiently anonymized/indexed when accessed by the server's moderation team. Encrypting the IP addresses is not enough, please have a different marker to go by such as the tsuserver3 IPID system.  
   1. If anyone besides the server owner also has access to people's IP addresses and/or Hardware ID's you must disclose who has access in the server listing's description.  
6. If your server requires verification for the users, such as registering an external account, Discord/Google/GitHub authentication (oauth2) or minimal playtime, please make sure to sufficiently communicate it to the user from within the Attorney Online client itself and mention it in your server listing's description.  
7. Your own server's rules and conditions must either be present in your server listing's description or linked to a page where the rules are easily accessible, if it's your own website or a google doc. You are also not allowed to force making an account or signing up to read these rules (such as a Discord account or an account on your website).  
8. For your server content, you must provide a direct download link or a link to a google doc/a web page where the server content may be downloaded from in your server listing's description. The minimal server downloads must be easily accessible as a direct download or the webpage/google doc that has the direct downloads linked.  
   1. You are not allowed to force making an account or signing up to anything (such as a Discord account or an account on your website) just to download the content.  
9. Your server must be 13+ at minimum (the same age rating as the Ace Attorney series).  
10. Make sure to include an 18+ label in the server's name if your server is adult-oriented. The server listing's description must tag the kind of adult content that may be featured on the server (Slurs, NSFW). An 18+ label means your server will not be featured on the master server listing by default unless the user opts in, this option will not be available on the [WebAO](https://github.com/AttorneyOnline/webAO) client. Your server MUST be labelled 18+ in these cases:  
    1. If slurs, derogatory terms and excessively graphic visual depictions of mutilation/gore are allowed in public, your whole server must be labelled 18+. Otherwise only private spaces that allow such content must be labelled 18+.  
       1. Descriptions of mutilation/gore without accompanying visuals do not fall under this rule.  
    2. If explicit sexual acts and/or explicit nudity are allowed ANYWHERE on your server (public or private) you must be labelled 18+.  
       1. Explicit nudity means exposed genitalia, anuses and exposed female breasts (nipples/areolae visible) are forbidden from being visually depicted without an 18+ label.  
       2. Explicit sexual acts means sexual intercourse, masturbation or physical sexual stimulation that is visually shown or described in detail.  
       3. General conversation, off hand sexual remarks and flirting do not fall under this rule unless it crosses the boundary into sexually stimulating talk where progression of explicit sexual acts or explicit nudity is described in detail.  
    3. Your server is not allowed to contain explicit sexual acts and/or explicit nudity of underage characters. You will be immediately delisted.  
11. Your server listing name and description are not allowed to feature any 18+ content. You are not allowed to publicly distribute 18+ content. You are not allowed to stream 18+ content via a content delivery network (CDN).  
12. Don't post unrelated links in your server listing's description, all links must lead to content and information directly related to your server or other servers/the attorney online community/source code of the software you are using/etc. Unsolicited advertising, spam will be grounds for immediate delisting.  
13. You will be immediately delisted for organizing raids against other servers and communities. If you and your moderation team are made aware of raiding campaigns you must also punish the raiders or you will be complicit and taken off the server list.  
14. The information sent to the server listing about your server must be accurate. If your server listing sends extra information (for example, player count) it must not be spoofed and reflect unique connections to the server rather than multiple connections from the same IP.  
    1. This rule will have a grace period of 2 months from the date of the release of these rules before it is fully enforced as there exists a security flaw with the desktop clients where clicking on a server already creates an active connection with it, exposing your IP address to the server. Additionally there is currently no way for the current server listing to know your server's player count.  
15. Don't do anything illegal. Don't distribute viruses or disturbing imagery (e.g. real-world gore, CSAM). Your server is not allowed to publicly endanger minors by allowing adults to knowingly engage in sexually charged conversations and flirt with them. Your server is not allowed to publicly disclose any personally identifying information to the public without that person's consent (doxxing), engaging in server-wide targeted harassment or being complicit in targeted harassment. You will be immediately delisted and banned for breaking the law.  
    1. If you or someone else is in immediate danger please contact your local law enforcement agency as soon as possible.
